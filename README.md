# Antigravity Playground

**An Autonomous Agent Engineering Framework**

This repository is configured as a production-ready environment for AI coding agents operating under the **Antigravity Protocol**.

## Quick Start

### For Agents
```
Read `.antigravity/AGENT_OS.md` and execute it sequentially.
```

### For Humans
1. Clone this repository
2. Run `npm install`
3. Run `npm test` to verify integrity
4. Open an agent session and provide your Product Vision

## Directory Structure

```
.antigravity/       # Agent Brain & Memory
├── AGENT_OS.md     # Executable Operating System
├── BOOTLOADER.md   # Initialization Checklist
├── TRAINING_MANUAL.md  # Full Protocol Documentation
├── config.json     # Autonomy Level & Budget

└── skills/         # Crystallized Knowledge

docs/               # Governance & Knowledge
├── ARCHITECTURE.md # System Design
├── CONSTITUTION.md # Safety Rules
└── TASKS.md        # Recurring Workflows

src/                # Application Code
tests/              # Verification Suite
AGENTS.md           # The Kernel (Stack, Commands, Rules)
```

## Autonomy Levels

| Level | Description |
|-------|-------------|
| **1** | Interactive - Agent proposes, human merges |
| **2** | Supervised - Agent executes, CI verifies, human approves |
| **3** | Autonomous - Agent auto-merges if CI passes |
